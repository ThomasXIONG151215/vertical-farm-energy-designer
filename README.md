# Vertical Farm Energy Designer (VFED)

Parametric, config-driven design simulator for plant factories (PFAL / vertical
farms). It couples a **digital-twin (ODE) building model** — room heat & mass
balance with configurable envelope, HVAC, dehumidifier, LED and plant
transpiration — to a **PV-Battery-Grid (PVBES)** energy system that optimises
solar-array size and battery capacity for minimum LCOE.

## Design philosophy

* **All parameters live in a YAML project file** — easy to create new designs and
  test many combinations (envelope structure, AC & dehumidifier params, LED,
  transpiration law, PVBES, tariff).
* The building load is generated by a first-principles ODE solver (no EnergyPlus),
  reusing the physics of the archived `digital_twin_core`.
* The PVBES layer reuses the single-diode PV + battery + LCOE model of the
  original `xiong-pvbes-photoperiod-2026` work.

## Layout

```
src/
  physics/      psychrometrics, envelope (heat+mass transfer), ODE solver, SHR
  devices/      hvac, dehumidifier, led, transpiration, compressor, lag
  weather/      weather_bridge (Open-Meteo + Erbs GHI split + POA + cache)
  pvbes/        pv (single-diode), battery (Zhao 2024), grid (TOU), energy_system
  design/       project (YAML), engine, presets, sweep
  agent/        evaluator (preserves the agent-cli error-code contract)
  cli.py        vfed: design new / optimize / evaluate / sweep
research/
  xiong-pvbes-photoperiod-2026/   original simulation code (archived)
  digital_twin_core/              vendored physics core (reference only)
```

## CLI

```bash
vfed design new my_farm --preset 609 --lat 30.9 --lon 121.5 --year 2023
vfed optimize my_farm.yaml --cache weather_cache --out results.csv
vfed evaluate my_farm.yaml --pv-area 120 --battery 40
vfed sweep my_farm.yaml --out sweep_results.csv
```

## Original code

The EnergyPlus-based load generator and the original optimizer live under
`research/xiong-pvbes-photoperiod-2026/` (see `README_archive.md` there). The
609 digital-twin physics is vendored under `research/digital_twin_core/`.
