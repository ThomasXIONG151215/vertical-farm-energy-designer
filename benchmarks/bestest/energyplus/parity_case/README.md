# VFED × EnergyPlus 逐时重合验证案例（普通建筑）

> 生成于 2026-10-26，vfed git sha `1b5db18`， harness `benchmarks/bestest/energyplus/parity_case.py`。

## 1. 案例定位

本案例验证 VFED 的**建筑物理核**在普通建筑工况下与 EnergyPlus 的逐时（8760 小时）一致性。“普通建筑”指无植物蒸腾、无 PVBES（光伏-电池-电网）调度的单区建筑：

- **案例 600 / 900**：ASHRAE Standard 140-2020 恒温工况（20 °C 供热 / 27 °C 供冷），轻型（600）与重型（900）围护；
- **案例 600FF / 900FF**：同围护的自由浮动（无 HVAC）工况，考核纯热动力学时序。

建筑几何：6 m × 8 m × 2.7 m 单区（48 m² 地面，129.6 m³），南向 12 m² 单层玻璃窗，200 W 内部得热（80 W 对流 + 120 W 辐射），渗透 0.414 ACH（丹佛海拔修正）。

## 2. 对照组：EnergyPlus 23.1

NREL 不分发 ASHRAE 140 的 idf 文件。本仓库 `build_idf.py` 从 LBNL modelica-buildings 的 Case*.mo 定义重建了 idf，运行 EnergyPlus 23.1 生成逐时参考。idf 保真度由 ASHRAE 140-2020 官方年度验收带判定（`user-gym/benchmarks/energyplus_report.md`：**14/14 指标 PASS**），因此 E+ 侧具备作为逐时参考（tier-3）的资格。2026-10-26 为四子图需求向全部案例 idf 追加了 Zone Air Relative Humidity 小时输出（仅输出请求，不改变物理；重跑后年度总量与此前逐位一致，复验仍 14/14 PASS）。

## 3. VFED 侧模型与对齐

- VFED 为纯 Python ODE 求解器（一维有限差分墙体 `wall_fd_nodes` + 集总空气节点，dt = 60 s），墙体层结构取 ASHRAE 140 定义原文。
- 天气：双方使用同一 Denver Intl AP 725650 TMY3 EPW；VFED 侧由 EPW 合成南垂直面 POA 辐照（NOAA 太阳位置 + 各向同性天空，rho_g = 0.2）。
- 周期稳态：两年串联仿真，第 1 年洗出初值，报告第 2 年。
- 对齐约定：E+ 小时结束行 h 对 VFED 第 2 年小时 h，各 8760 行。
- 恒温器：`photoperiod = 24 h` 使 T_light = 27 全年制冷设定、T_dark = 20 供热设定；理想设备（无风机电耗；制冷 8 kW 电 × COP 3 = 24 kW 热、电阻供热 8 kW 热，覆盖 ASHRAE 140 峰值参考区间所需的容量裕度）。

## 4. parity 参数集（校准结果）

校准目标从 ASHRAE 140 年度带切换为 **E+ 逐时序列**（tier-3 参考）。四波共 95 个候选的定向扫描（逐行记录 `parity_scan_*.json`，排序工具 `pick_best.py`）表明：恒温器比例带 `mod_band_c` 是二阶旋钮（波 1 实测对 RMSE/年差影响 < 0.5 个百分点），保持默认 1.0；起决定作用的旋钮是直连通道 UA（夜间有效传热系数对齐）、窗户太阳能系数与外墙太阳吸收率（太阳得热分配）、内部质量节点热容（重型墙蓄热回放）与空气节点热容（自由浮动摆幅）。600 族（600/600FF）采用**完全相同**的参数集（同一物理建筑，族一致性已验证：600FF 损失仅 0.06 °C RMSE）；900 与 900FF 分别标定——族集用到 900FF 会劣化到 1.905 °C RMSE（劣于基线 1.794），该族不一致已量化并在此披露。

## 5. 逐时重合指标（全年 8760 小时）

“完全相同”的工程界定：两个独立求解器（E+ 传热反应系数法 vs VFED 有限差分 ODE）不可能逐位一致；本案例做到的是**逐时序列重合**——曲线肉眼不可分、统计指标达到下表水平，残余差值在第 8 节逐项归因。与 harness 基线相比（600 供热 +7.8%、900 供热 +18.7%），parity 集把全部年负荷差压进 |≤3.2%|；600 的室温 RMSE 从 0.52 升到 0.57，换取的是负荷序列重合（综合目标函数 4.63→1.35），权衡已在扫描记录中披露。

## 8. 残差归因（两求解器的已知结构差）

- **太阳位置与逐时辐照处理**：E+ 按亚小时太阳位置细分直射/散射并按入射角修正玻璃透过率；VFED 用小时中点太阳位置 + 常数太阳能系数（isotropic-sky POA 补偿环日低估）。
- **长波交换**：E+ 含天空/周围表面长波项；VFED 墙体无夜空长波散热通道（以直连通道 UA 微降补偿，900 族 `ua` 偏离 140 名义值即源于此）。
- **墙体导热**：E+ 用状态空间 CTF（逐层构造 + 内外表面膜系数 + 辐射分配）；VFED 为 1-D 有限差分链 + 集总内部质量节点，表面吸热分配为标定等效。
- **恒温器**：E+ ideal loads 逐步精确贴合设定点；VFED 为比例带控制器（parity 集保持默认 1.0 °C 比例带），供热时段存在约 0.2–0.3 °C 的稳态比例偏移，已计入室温 MBE，并贡献 600 供热年差 +1.1% 中的主要部分。
- **对齐口径**：E+ 小时行是亚小时积分的小时汇总，VFED 为 60 s 步长积分后按小时分桶，极值小时存在相位差。

## 10. 范围边界

- 湿工况案例 600p（加湿源 + 除湿机交叉验证）为植物工厂前身场景，不在“普通建筑”范围，且除湿机控制模式存在已归因的结构差（见 `energyplus_hourly_report.md`）。
- 本案例只考核建筑核：不含 PV / 电池 / 电网调度与植物模块。
