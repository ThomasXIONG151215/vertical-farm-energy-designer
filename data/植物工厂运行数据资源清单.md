## 三、快速选用建议（针对能源仿真项目）

| 需求 | 推荐 |
|------|------|
| 真实能耗 + 环境时序 + 产量（一个数据集全含） | **AGC 2018/2019（WUR）**——含加热/电耗/CO₂/水和完整设施背景 |
| 长时序环境验证模型 | 比利时番茄 2018–2020 多年数据（#5） |
| 垂直农场（人工光）能耗基准 | 意大利垂直农场 LCA 数据集（#4）+ 论文类 Graamans/Kozai/Martin 系列 |
| 快速获得大量案例的 kWh/m²、kg/m² 基准值 | Frontiers 附录 Table 1（人工提炼） |
| 能耗基准量级参考 | 实测集中在 **7–12 kWh/kg**（高效日本厂）至 **20–40 kWh/kg**（欧美商业厂）；产量 40–520 kg/m²/年 |
