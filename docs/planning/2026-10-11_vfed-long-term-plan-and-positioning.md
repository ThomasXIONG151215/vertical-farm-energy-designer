## 1. 定位（Positioning）

### 1.1 一句话定位

一个**配置驱动、机理为先、数据可校准**的室内种植能源仿真平台：以「合格的建筑能源仿真器」为根基，向上生长出植物生长耦合仿真能力，最终成为设施农业专用能源仿真器，并以「一维仿真 + 机器学习辅助校准」作为极致差异点。

### 1.2 三层递进定位（优先级从高到低）

| 层级 | 定位 | 合格标准 |
|------|------|----------|
| L1 | **合格的建筑能源仿真器** | 通过 BESTEST（ASHRAE 140）类基准验证；围护结构传热、湿平衡、空气侧热质平衡可信 |
| L2 | **+ 植物生长仿真器** | 蒸腾/生长模型有实验数据参照（UC Davis、北京农林科学院等）；生菜、番茄两类作物参数化 |
| L3 | **设施农业专用能源仿真器** | LED-距离-光谱、COP-室内外气候-部分负荷、除湿-SHR 等设备级保真度足以支撑控制优化策略研究 |

**原则**：仿真必须严格。L1 不合格则 L2/L3 的结论不可信；每一层都要有独立于自身代码库的验证参照物。

### 1.3 普适性目标（Universality）

1. **多种室内种植类型**：植物工厂（人工光型）为第一支持对象；未来可能覆盖集装箱农场、生长室等 → 触发更名 **IFED**（Indoor Farm Energy Designer）的评估（见 §6 Q1）
2. **数据校准引擎**：支持任何人用自己的历史数据（时序 + 设施背景描述）对模型进行校准；校准结果受物理合理性约束（见 §4 贯穿能力线）
3. **仿真组合自由**：温湿度仿真、作物仿真、能源系统仿真可单选或多选耦合
4. **模型范式可选**：纯机理（第一性原理 ODE）/ 机器学习（代理模型）/ 混合模型（机理骨架 + ML 校准或残差学习）

### 1.4 差异化主张

- **一维仿真 + 机器学习辅助校准，做到极致**：不做三维（见 §2.2），把「一维可校准」做成比「三维精细化」更实用、更可信、更普惠的路线
- **开放校准**：不是黑箱仿真器，而是「带来你的数据，得到你设施的模型」的平台

## 2. 做与不做（Scope）

### 2.1 做（In Scope）

| 能力域 | 具体内容 | 现状（VFED 当前代码库） |
|--------|----------|------------------------|
| 仿真维度 | 一维单点仿真（集总参数 ODE） | ✅ `vfed/physics/ode.py` 纯 Python ODE |
| 传热传质 | 传统单区传热传质；沿用林涛团队的三区传热传质（蓝本已确认为 EnergyCEA，见 §6 Q2） | ✅ 单区 envelope + SHR；三区划分待引入 |
| 环境状态量 | 温度、湿度、CO₂ 浓度 | 温/湿 ✅（psychrometrics）；CO₂ ❌ 未容纳（`setpoints.co2_ppm=800` 仅为 VanHenten 固定输入，非状态量；补充方案见 §6 Q5） |
| 作物模型 | 植物生理模型：生菜、番茄 | 部分：Van Henten 1-state 生长（生产路径）+ 5 种蒸腾方法；3-state（X_d/C_buf/LAI）集成立项中（v0.5，见 §4 Phase 1.3）；按生菜/番茄分列的参数化待完善 |
| 建筑对象 | 植物工厂建筑（人工光型） | ✅ preset 体系（如 609） |
| 能源设备 | 光伏、储能、空气源热泵、水源热泵、新风机 | PV/电池/电网 ✅（pvbes + sweep）；HVAC Carnot COP ✅；ASHP 专项 / WSHP / 新风机 待建设 |
| 校准机制 | 机器学习校准机制 | ❌ 未建（校准引擎贯穿能力线核心，见 §4；作物侧手工校准实践已在 benchmark 层完成首批案例） |

### 2.2 不做（Out of Scope）及理由

| 排除项 | 理由 |
|--------|------|
| 表型图像 | 非能源仿真核心，避免范围蔓延 |
| 三维仿真 | 多层补光 + 自然光混合、叶片/结构遮挡必须三维才能解决，超出一维路线主张 |
| 温室 | ① 灌溉问题与植物工厂完全不同；② 多层补光 + 自然光混合及遮挡需三维（与上一条同因排除） |
| 湿帘风机 | 温室/半封闭设施典型设备，全封闭人工光植物工厂不适用 |
| 辐射制冷 | 封闭围护体系下优先级低，排除 |

### 2.3 边界澄清

- **温室数据 ≠ 温室仿真**：不做温室仿真，但 AGC、BJAAF 等**温室数据集**有两个允许用途（细则见 §6 Q3）：① 验证蒸腾、作物生长等与围护结构弱相关的模块；② **校准生长模型参数**——品种相关参数（光截获、光能利用效率等）随品种/设施变化，温室数据可用于定参。仍禁止：用温室数据验证或校准围护传热、空调等建筑侧参数
- **EnergyPlus / BESTEST 仅作验证基准**：使用其公开基准结果做对比，**不引入运行时依赖**（遵守 AGENTS.md「No EnergyPlus dependency」约束）

## 3. 痛点 → 需求映射

| # | 痛点（原意提炼） | 对应需求 | 验收标准 |
|---|------------------|----------|----------|
| P1 | 现有仿真极大简化植物模型、验证不足；应先确保植物生长模型正确或有参照对象 | L2 作物模型验证体系：实验数据参照 + 多数据集交叉验证 | 生菜/番茄蒸腾+生长在 ≥2 个独立数据集上达到可报告误差指标（如蒸腾 RMSE、收获鲜重偏差 %；作物参数允许每数据集手工校准，口径见 §4 Phase 1） |
| P2 | LED 与空调模型过度简化（与植物距离、光谱、COP、室内外气候差异），关键能源系统粗化无法支撑控制优化策略 | 设备保真度提升（Phase 2）：LED 距离/光谱、COP 曲线族、ASHP/WSHP/新风机机理模型 | 设备级模型有厂商曲线或文献参照；含室内外温度依赖的 COP 预测误差可量化 |
| P3 | 全模拟或仅单设施验证，未在更普遍的建筑能源系统里检验机理漂移，过拟合风险 → 缺基准缺可靠性 | L1 基准资格 + 多设施交叉验证（Phase 1） | ① BESTEST/ASHRAE 140 类对比通过；② ≥3 个独立设施数据集验证；③ 能耗强度落位论文基准带（高效日本厂 7–12 kWh/kg 至欧美商业厂 20–40 kWh/kg） |
| P4 | 数据有干扰、参数不可得、设备内部效率曲线不可得时，无基于部分历史数据回溯校准且结果合理的机制 | 校准引擎贯穿能力线（§4）：可辨识性分析 + 带物理先验的参数估计；各 Phase 渐进贡献（Phase 1 作物手工校准 → Phase 2 设备侧 → Phase 3 自动化与开放接口） | 数据缺失/含噪场景下，校准参数落在物理合理区间，预测误差与置信区间可报告 |

## 4. 长期路线图（Roadmap）

> 原则：**先可信、再保真、再普适**。每个 Phase 有明确出口标准，未达标不进入下一阶段核心目标。
> **结构（v0.4）**：四阶段（Phase 0-3）+ 一条贯穿能力线（数据校准引擎）。校准引擎不是串行阶段，横切所有 Phase。每个 Phase 显式定义校准引擎的角色与出口。

### 贯穿能力线 — 数据校准引擎（对应 P4，核心差异化）

> v0.4 升维：原 Phase 3（数据校准引擎）的全部内容抽出，升为贯穿能力线。阶段编号从五阶段（0-4）改为四阶段（0-3）。

- **定位**：校准引擎是横切能力，不是串行阶段。依据有三：① Phase 1 作物验证天然包含手工校准（BJAAF 锚定 + UC Davis 迁移实践已证）；② Phase 2 设备参数（COP 曲线、LED 光效）同样需要数据定参与可辨识性分析，与作物侧同一方法论；③ P4 本质是横切需求——任何时候数据有干扰都需要回溯校准。各 Phase 的角色：Phase 1 积累手工校准经验与设计知识；Phase 2 把方法论扩展到设备侧；Phase 3 集中建设自动化并产品化为开放接口
- **四层架构（设计沉淀，各 Phase 渐进填充）**：
  1. **输入适配层**（v0.3.2 双适配器架构）：用户部分历史数据 + 设施背景描述 → 结构化校准任务。按数据集形态分两条等价路径，产出同一截获锚（c_pl_d 观测）：
     - **适配器 A（比值型）**：数据集有同株同日 LAI/X_d 配对测量（BJAAF 型）。比值型观测破参数简并且无需通量推断。测试用例：BJAAF（Stage 1 手工版已完成，c_pl_d=32.7）
     - **适配器 B（图像型）**：数据集无 LAI/X_d、有冠层图像（UC Davis 型）。绿色像素占比直测截获项 (1−e^(−c_pl_d·X_d))。测试用例：UC Davis（727 张冠层 RGB，图像识别待实现；2026-10-16 决策保留为图像适配测试用例）
     - **适配器 B 边界**：图像只破截获轴简并。无实测 PAR 的数据集，效率乘积（c_rad_phot × PPFD × 1/ρ）仍简并。校准值为条件值（依赖 PPFD 假设），需跨数据集迁移补锚
  2. **可辨识性层**：分析哪些参数该数据能约束、哪些不能。BJAAF/UC Davis 案例中的 K_eff 四因子简并分析为首批实践样例
  3. **参数拟合层**：贝叶斯后验 / 代理模型优化 / 混合（机理骨架 + ML 残差），物理先验约束参数合理域（技术选型见 §6 Q4）
  4. **输出层**：校准参数 + 置信区间 + 漂移/失效诊断 + **可辨识性标签**（v0.3.2）——每个参数标注来源四类之一：直接锚定 / 拟合 / 迁移 / 假设（「开放校准」主张的前提）
- **演进逻辑**：手工校准实践（Phase 1，作物侧，BJAAF Stage 1/2 已完成）→ 设备侧扩展（Phase 2，厂商曲线/文献定参）→ 自动化建设与产品化（Phase 3，开放校准接口）
- **防失焦约束**：「贯穿」≠「分散」。自动化校准的工程实现集中在一个建设期（Phase 3 前段）。各 Phase 贡献的是输入、适用面扩展与设计知识，不是各自平行造引擎

### Phase 0 — 现状基线（已具备）

- 一维 ODE 建筑模型（psychrometrics / envelope / SHR）+ 5 种蒸腾方法 + Van Henten 生长
- 设备：HVAC（Carnot COP 默认）、除湿机自整定、LED、压缩机（含滞后）
- PVBES：PV-电池-电网 + sweep 寻优（LCOE 导向）
- 天气：Open-Meteo + 城市缓存库；Web 前端（Pyodide 后端无关）
- **结论**：L1/L2 的「资格认证」尚未完成 —— 正是 Phase 1 的动机

### Phase 1 — 可信性优先：基准与验证（对应 P1/P3）

- 1.1 L1 资格：BESTEST（ASHRAE 140）对比报告（围护/单区热平衡）
- 1.2 设备基准：COP 模型 vs 文献/厂商曲线；能耗强度落位论文基准带
- 1.3 作物验证：UC Davis 生菜（30 min 环境时序 + 逐日鲜重）、北京农林科学院生菜、AGC 2022（4TU 恢复后）；番茄沿用 Van Henten 原始参数系
  - **生长模型结构升级——Van Henten 3-state 集成（v0.5 立项，2026-10-22 用户决策）**
    - 依据：结构诊断（`user-gym/benchmarks/uc_davis_structure_diagnosis_report.md`）证明截获-干重比例时变是主残差源。同单参数自由度下 RMSE 15.75→6.27 g，终点 152.3 vs 实测 152.8 g，S 形残差消失。换算链（dry_frac 时变）阴性排除。残差形态三数据集复现（Exp_c / UC Davis / Exp_v2）
    - Step 1（脚本层数值验证）：同方程换 vfed 同款 600 s 显式 Euler，对四轨道（BJAAF Exp_c / v1 / v2 + UC Davis proxy）对比 RK45。判定线：差 <0.5%。C_buf 快平衡池的步长稳定性在此暴露
    - Step 2（vfed 集成，动 `plants/` 已获用户批准）：`vfed/plants/` 新 3-state 类（状态 [X_d, C_buf, LAI]，参数组 SLA/σr/ε₀/k_PAR）；`project.py` 增 `growth.model` 字段（默认 `van_henten` 保 609 零漂移）+ `presets.py` 同步；`engine.py` 三状态接口扩展（M1 CO₂ `fluxes()` 兼容）。门禁：全量 pytest + 609 基线零漂移 + 四数据集回归
    - 对校准引擎的影响：LAI/X_d 配对数据的锚定目标从 c_pl_d（1-state 混合常数）切换为 SLA / σr / LAI₀（3-state 物理分解参数）。适配器 A 数据形态不变
  - **结构升级候选管道（v0.5 入档；立项条件 = 所需数据到位 + 可辨识性预判通过）**
    | 候选 | 内容 | 所需数据 | 状态 |
    |---|---|---|---|
    | 呼吸分离 | 生长呼吸/维持呼吸分离（McCree 型），替换单 Q10 项 | M1 CO₂ 夜间平衡信号（609 逐时 CO₂）；BJAAF 夜间 CO₂（温室土壤呼吸混杂，弱证据） | **推进中（2026-10-22）** |
    | 温度响应解耦 | 最适温随发育阶段移动（现抛物线钉死 22.5°C） | 温度阶梯实验；BJAAF v1 春季自然温漂仅弱信号 | 候选 |
    | 多层冠层 | sunlit/shaded 双叶冠层光合 | PFAL 光均匀，3 层高斯求积已足 | 低优先 |
    | 光质响应 | 红蓝比/光谱配方进入生长方程 | LED 光质实验数据 | 无数据，远期 |
    - 呼吸分析推进路径（R 线，2026-10-22 启动）：R1 数据源盘点（609 TableStore / AGC zip 可用性、BJAAF 夜间时段提取）→ R2 可辨识性预判（单 Q10 项 c_resp_d 在夜间暗期数据下能否分离）→ R3 分析脚本（夜间时段模型呼吸项 vs 数据约束对比）→ R4 报告（`user-gym/benchmarks/`）
- 1.4 多设施交叉：AGC 2018/2019（限作物/蒸腾模块层面，见 §2.3）
- **验证对象口径（v0.3 精化）**：作物验证的对象是**模型结构有效性**——存在一组物理合理参数使模型匹配实测数据，即认为结构通过。允许（且通常必要）**每数据集手工校准**品种相关参数后再报告误差。依据：物理模块（围护/HVAC）参数通用，可直接用文献默认值验证（BESTEST 已证此路径）；作物参数品种/设施强相关，此差异是客观物理性质而非模型缺陷。自动化校准与置信区间归贯穿能力线的集中建设期（Phase 3 前段），不在本阶段出口标准内
- **校准引擎角色（v0.4）**：作物手工校准实践 = 校准引擎首批设计输入与测试用例。BJAAF 适配器 A（比值型）Stage 1 手工版已完成（c_pl_d=32.7）；UC Davis 适配器 B（图像型）待实现。验证报告中的参数简并分析（K_eff 四因子）是可辨识性层的首批样例
- **出口标准**：形成验证报告体系（如 `validation/`），P1/P3 验收达成；沉淀「哪类数据能约束哪些参数」的手工校准操作知识

### Phase 2 — 设备与系统保真度（对应 P2）

- LED：安装高度 → 冠层 PPFD 分布（距离衰减/余弦）、光谱配方（R/G/B、光效 μmol/J）、光衰
- 空调/热泵：COP-室内外温度-部分负荷曲线族；ASHP 结霜降额；WSHP 水侧边界条件
- 新风机：ERV 显热/全热交换效率、旁通控制
- 与 PVBES 耦合的运行策略仿真（支撑控制优化研究）
- **校准引擎角色（v0.4）**：设备参数同样走数据定参路径。COP 曲线族靠厂商曲线/文献校准；LED 光效/光衰靠文献数据校准。设备侧可辨识性分析（哪些参数该曲线能约束、哪些不能）与作物侧同一方法论
- **出口标准**：设备级误差可量化，端到端能耗预测在验证数据集上达标；设备参数校准流程可复现

### Phase 3 — 普适化与平台化（对应 §1.3）

- 作物扩展（生菜 → 番茄）、设施类型扩展（植物工厂 → 集装箱农场/生长室）
- 仿真组合可选（单选/多选耦合）、模型范式可选（机理/ML/混合）
- **校准引擎角色（v0.4）**：自动化校准的集中建设期在本阶段前段（Q4 技术选型在此前定）；开放校准接口（CLI + Web）= 校准引擎的最终产品形态，兑现「带来你的数据，得到你设施的模型」平台主张
- **IFED 更名决策点**（§6 Q1）
- **出口标准**：≥2 类室内种植设施类型端到端可用；第三方数据可复现校准流程，P4 验收达成

## 5. 数据战略（三类数据）

### 5.1 普适性建筑与系统能源数据（服务 L1/L3 验证）

- **BESTEST / ASHRAE 140**：建筑热平衡资格认证基准
- **EnergyPlus 公开算例结果**：对照用（仅验证，无运行时依赖）
- **其它论文**：光伏系统参照（如 pvlib 生态基准）等

### 5.2 作物实验数据（服务 L2 验证，对应 P1）
